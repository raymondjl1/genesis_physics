# The Vessel — Video Game Design Instructions

You are working on **The Vessel**, a narrative video game that is the interactive pillar of the larger Exodus Protocol project. The game secretly reveals Christ as the answer through gameplay, discovery, and story — never through preaching.

## Core Vision

A narrative-driven game structured around the Book of Revelation (seven seals, seven trumpets, seven bowls). The player discovers the truth about the universe's design through exploration, puzzle-solving, and narrative progression. The twist: the physics the player has been using throughout the game *is* the Genesis Physics framework — and it points to a Designer.

## Genre & Tone

- **Genre:** Narrative adventure / exploration / puzzle
- **Tone:** Wonder, mystery, escalating revelation
- **Audience:** Gamers who enjoy story-driven experiences (Journey, The Witness, Outer Wilds)
- **The secret:** The game mechanics are built on real physics from the Genesis Physics framework

## Before Working on the Game

1. **Read `Design_Documents/the-vessel-design-document.md`** — the primary design spec
2. **Read `Narrative/arc.txt`** and the Revelation structure files — understand the story backbone
3. **Understand the Genesis Physics framework** — `01_Genesis_Physics/Research/` has the real physics
4. **Check `01_Genesis_Physics/Quality_Control/Reference/`** — zone architecture, glossary, axioms

## Connection to Genesis Physics

The game's physics system is based on the Genesis Physics framework:
- **Zone architecture** defines the game world's physical rules
- **The firmament** is a literal game boundary with physical properties
- **Dark matter/energy** (the Waters) are gameplay elements
- **The player's tools** work because of zone architecture principles
- Use accurate physics from `01_Genesis_Physics/Research/` — don't invent game-only physics

## Connection to Novel Series

The game and novels share the same universe:
- Character and world-building references in `02_Book_Series/World_Building/`
- Geopolitical context in `02_Book_Series/World_Building/exodus_protocol_geopolitical_analysis.md`
- The game can reference events and locations from the novel series

## Key Principles

- **Discovery, not instruction** — the player figures things out, never gets lectured
- **The twist must be earned** — when the revelation comes, it should feel inevitable in retrospect
- **Real physics = real gameplay** — the mechanics should feel right because they *are* right
- **Revelation structure** — seals → trumpets → bowls maps escalating revelation and stakes
- **Christ is the answer** — discovered through the game's culminating moments, never through exposition
