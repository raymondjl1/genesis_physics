# Equation Registry

**Purpose:** Canonical record of all equations in the Genesis Physics Series, using the permanent numbering scheme: (V.Ch.Eq) where V = Volume, Ch = Chapter, Eq = Equation number within chapter.

**Status:** Living document — populated as chapters are written. This registry is the source of truth for equation references across all volumes.

**Numbering Scheme:**
- Format: (Volume.Chapter.EquationNumber)
- Example: (1.3.14) = Volume 1, Chapter 3, Equation 14
- This numbering is PERMANENT — once assigned, it never changes, even if equations are moved between editions
- Each volume resets equation numbering at chapter boundaries
- Equation numbers must be unique within a chapter

## Notes

**How to use this registry:**

1. When writing a new chapter in any volume, assign equation numbers sequentially within that chapter starting at (1): (V.Ch.1), (V.Ch.2), etc.
2. When referencing an equation from a prior chapter or volume, cite it by its full (V.Ch.Eq) number: "As shown in (1.3.14)..."
3. NEVER renumber an equation once it's published, even if later editions move text around
4. If an equation is derived from a prior equation, note the dependency in the description
5. If an equation is missing from this registry but should exist, add it immediately with all fields filled in
6. This registry is checked by the Consistency Auditor during every validation cycle

**Maintenance:**

- Add entries for each new chapter as it moves to draft-complete status
- Run automated scans on finalized chapters to extract equation numbers and auto-populate this registry
- Cross-check against downstream volumes to verify no duplicates or conflicts
- Update descriptions if equations are reinterpreted or clarified in later volumes (but DO NOT change the equation number)
