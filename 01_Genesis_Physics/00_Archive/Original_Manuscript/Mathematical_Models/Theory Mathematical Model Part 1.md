## 6. From Identity to Differential Equations

### 6.1 The Concept of Change

If 1 = 1 always, how does anything change?

**Answer**: By *rates* of change, not absolute values.

Let 1 represent a **constant**:
```

```

The derivative of constancy is zero.

**But**: If we have a *function* f(t) = 1 for all t:
```
f(t) = 1
f'(t) = 0
f''(t) = 0
```

### 6.2 Wave Equation from Identity

Consider the statement: "What is must remain what is, but can oscillate around equilibrium."

**Equilibrium**: f = 1
**Perturbation**: f = 1 + h (where h is small deviation)

**Restoring force**: System wants to return to f = 1

**Simplest equation** capturing this:

**Solution**: h(t) = A cos(ωt) + B sin(ωt)

**Result**: **Oscillation** (waves, cycles)

**Connection to framework**:

### 6.3 Diffusion from Symmetry

If 1 is same everywhere (space symmetry), then any *deviation* from uniformity must dissipate:

**Diffusion equation**:

Where ρ is density.

**Physical interpretation**:
