# MODEL 15: DNA INFORMATION LIMITS

## 15.1 Information Theory Basics

### 15.1.1 Shannon Entropy

**For discrete symbols** with probabilities p_i:
```
H = -Σ p_i log₂ p_i
```

**Maximum**: When all p_i equal (uniform)

**For DNA** (4 bases A, T, G, C):
```
H_max = log₂(4) = 2 bits per base
```

### 15.1.2 Human Genome

**Size**: ~3.2×10⁹ base pairs

**Maximum information**:
```
I_max = 3.2×10⁹ × 2 = 6.4×10⁹ bits ≈ 800 MB
```

**But**: Not all information-bearing

## 15.2 Actual Information Content

### 15.2.1 Coding vs. Non-Coding

**Protein-coding**: ~1.5% of genome (~20,000 genes)
```
I_coding ≈ 0.015 × 6.4×10⁹ ≈ 96 Mb
```

**Regulatory**: ~3-5% (promoters, enhancers, etc.)
```
I_regulatory ≈ 0.04 × 6.4×10⁹ ≈ 256 Mb
```

**Conserved non-coding**: ~3-5%
```
I_conserved ≈ 256 Mb
```

**Total functional**:
```
I_functional ≈ 96 + 256 + 256 ≈ 600 Mb
```

**Junk DNA**: ~90%
- Repetitive elements (SINEs, LINEs)
- Pseudogenes
- Low information content

### 15.2.2 Effective Compression

**Redundancy reduces** information:

**Codon degeneracy**: 64 codons → 20 amino acids
- Redundancy factor ~3.2
- Effective: 96 Mb / 3.2 ≈ 30 Mb for proteins

**Repetitive elements**: ATATATATAT...
- Low entropy (highly compressible)
- Contributes <<1% of information

**Kolmogorov complexity**: Length of shortest program
```
K(genome) ≈ 100-200 Mb (estimate)
```

Much less than 800 MB maximum.
