Every prompt below is a self-contained brief. Each one:

- Invokes the `genesis-chapter-writer` skill under the 6-phase lifecycle (Spec → Outline with figure plan → Draft → Self-Review → Reviewer Agents → Finalize)
- Names the files to read first, always starting with `../AUTHOR_VOICE_AND_BACKGROUND.md` (franchise voice source of truth) and this book's `CLAUDE.md` + `WRITING_PROMPT.md`
- Points to the specific **Book 0 Foundations volume(s) and chapter(s)** that contain the derivations this chapter rests on. **Book 0 is the encyclopedia; this book draws confidence from it but never reproduces its math.**
- Points to the corresponding **Book 1 (Popular Science Flagship) chapter(s)** that cover the same physics content, so the Family Edition stays synchronized with the flagship while remaining scripture-first

- Includes chapter-specific "special instructions" with the narrative hook, scripture-density target, teaching-tool requirements, and pitfalls to avoid

**Scripture cascade rule (biblical-first):** every main claim in this book must trace to a direct, correctly-contextualized biblical truth. Every subsequent claim must trace to a parent biblical claim already established, or to a new biblical truth introduced in the same chapter. Apply the "delete the verse" test: if a paragraph's claim survives unchanged after the scripture reference is removed, the scripture wasn't load-bearing and either the claim or the reference is wrong. Fix it before shipping.

**Physics cascade rule:** every physics claim in this book must also be derived in Foundations. If the Foundations source isn't complete when a chapter comes up, STOP writing, file a `Research Gap` issue, and move on. Do not hand-wave.

**Citation formats this book uses:**
- Scripture: *(Genesis 1:1, ESV)* or similar — translation specified on first use each chapter.
- Physics: *(See Foundations Vol X, Ch Y.)* — never "trust me."
- Popular-science handoff (for parents who want more): *(Book 1: The Hidden Architecture, Ch Y, covers this without the scripture frame.)*

## What Every Family-Edition Chapter MUST Include

These are the teaching-tool elements the Family Edition is built around. The `genesis-chapter-writer` skill will enforce them in Phase 1 (Spec), but every prompt below reiterates the requirement so nothing is accidentally dropped.

1. **Opening Scripture anchor.** Each chapter opens with a direct scripture quotation (not a paraphrase), chapter and verse, translation named.
2. **"Scripture says... and modern physics has discovered..." structure.** Every major concept is introduced in that order — Bible first, physics confirms.
3. **"But What About...?" section.** Every chapter addresses the questions kids (and skeptics) actually ask on that chapter's topic.
4. **Family Discussion Questions.** 4–7 questions at chapter's end, ordered from youngest child (elementary) → middle school → high school → parent-level.
5. **Key Terms callout.** A short glossary of the chapter's 3–6 new terms, defined for a Grade 9–12 reader.
6. **Scripture Memory Verse.** One verse pulled from the chapter's anchors, flagged for family memorization.
7. **Family Activity (where natural).** A simple home demonstration, observation, or discussion exercise tied to the chapter's physics.
8. **Voice.** The Family-Edition specialization of the canonical Jeff L. Raymond voice — reverent, confident, parent-to-parent, never preachy, never condescending. See `../AUTHOR_VOICE_AND_BACKGROUND.md`.
